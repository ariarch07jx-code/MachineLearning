# Markdown 速查笔记

> 这份文件本身就是用 Markdown 写的,你在 VS Code 里点右上角的「预览」图标(或 `Cmd+Shift+V`)就能看到渲染效果;看左侧源码 = 学语法。

---

## 1. 标题

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
```

`#` 后面要有一个空格。记笔记一般用到三级就够。

---

## 2. 强调:加粗、斜体、删除线

```markdown
**加粗**       →  **加粗**
*斜体*         →  *斜体*
~~删除线~~     →  ~~删除线~~
`行内代码`     →  `行内代码`
```

---

## 3. 列表

无序列表用 `-` 或 `*`,有序列表用数字:

```markdown
- 项目一
- 项目二
  - 子项(前面缩进两个空格)
  - 又一个子项

1. 第一步
2. 第二步
3. 第三步
```

渲染效果:

- 项目一
- 项目二
  - 子项
  - 又一个子项

1. 第一步
2. 第二步
3. 第三步

---

## 4. 链接和图片

```markdown
[链接文字](网址)
![图片说明](图片地址)
```

例子:

```markdown
[动手学深度学习](https://d2l.ai)
![架构图](./images/arch.png)
```

---

## 5. 代码块(记笔记最常用)

三个反引号 ``` 包起来,后面写上语言名可以有语法高亮:

````markdown
```python
import numpy as np
x = np.arange(10)
print(x)
```
````

渲染效果:

```python
import numpy as np
x = np.arange(10)
print(x)
```

## 6. 表格

```markdown
| 目录 | 内容 | 状态 |
|---|---|---|
| 01_python | 基本语法 | 待学 |
| 02_numpy | 数组运算 | 进行中 |
```

渲染效果:

| 目录 | 内容 | 状态 |
|---|---|---|
| 01_python | 基本语法 | 待学 |
| 02_numpy | 数组运算 | 进行中 |

> 竖线 `|` 要对齐不用手动数空格,VS Code 会帮你自动排版。

## 7. 引用

```markdown
> 这是引用,适合摘录书里的话,或标记"重点 / 踩坑"。
```

渲染效果:

> 这是引用,适合摘录书里的话,或标记"重点 / 踩坑"。

## 8. 分割线和任务清单

```markdown
---            ← 三个横线就是分割线

- [ ] 未完成的任务
- [x] 已完成的任务
```

渲染效果:

- [ ] 未完成的任务
- [x] 已完成的任务

## 记笔记的建议模板

每个算法笔记,可以用这套固定结构:

```markdown
# 算法名(如:线性回归)

## 一句话理解
(用大白话讲这个算法在干嘛)

## 核心公式
$$ y = w x + b $$     ← 数学公式,用两个 $ 包起来

## 代码复现
```python
# 关键代码
```

## 踩坑记录
- 坑 1:...
- 坑 2:...

## 参考资料
- [链接](网址)
```

> 数学公式那行用的是 LaTeX 语法(`$...$`),VS Code 的 Markdown 预览支持,后面写数学推导时很有用。
