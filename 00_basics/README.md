1. **Python 基本语法** —— 会写 Python 的话快速过一遍,重点看函数、列表推导式、类(class)。
2. **NumPy** —— 数组 / 矩阵运算,后面所有模型的数学基础。
3. **Pandas** —— 表格数据清洗、处理,做真实项目 / 比赛必备。
