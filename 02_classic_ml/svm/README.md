## 结论

| 实验 | 结果 |
|---|---|
| 线性可分数据,C=1 | 4 个支持向量,间隔 1.432,训练准确率 1.0 |
| 只用这 4 个支持向量重训 | 系数和全量训练差 0.0003 |
| C=0.05 / C=100 | 15 个支持向量、间隔 2.66 / 3 个支持向量、间隔 1.38 |
| 月牙形数据,三种核的 CV | 线性 0.865,多项式 0.853,RBF 0.903 |
| RBF 的 gamma=0.1 / 1 / 100 | 训练 0.879 / 0.917 / 0.971,测试 0.850 / 0.889 / 0.856 |
| 乳腺癌,未标准化 / 标准化 | 0.9122 / 0.9736 |
| 乳腺癌,线性核标准化 | 0.9701 |
| iris 多分类 CV | 0.9667 |

- 支持向量之外的点删掉不影响结果,这是 SVM 和逻辑回归最不一样的地方。
- C 小的时候间隔宽、支持向量多,C 大的时候模型死抠每个点,间隔被压窄。
- RBF 在这个数据上比线性核高 4 个点,gamma 从 0.1 调到 100 时,训练集一路涨,测试集先升后降。
- 不标准化直接上 SVM,乳腺癌数据只有 0.9122,标准化之后 0.9736。

## 踩坑

- 想用决策边界对比 C 的大小,但数据线性可分,两个 C 的边界几乎重合,图上看不出区别。改成看支持向量个数和间隔宽度才明显。
- 支持向量重训的结果差 0.0003 而不是 0,一开始以为把 `support_` 用错了,其实是 sklearn 的数值容差。
- `gamma` 不写时默认是 `"scale"`,等于 1 / (特征数 × 方差),不是 1。手动试 gamma 时要显式给值,不然和默认对不上。
- 特征缩放对 SVM 影响很大,乳腺癌数据差 6 个点。这个坑在 KNN 和 K-Means 上还会再踩一次。
- SVC 的时间和内存跟样本数的平方有关,几万条就撑不住了,大数据集要换 `LinearSVC` 或 `SGDClassifier`。
- 画决策函数时 `-1 / 0 / 1` 三条线分别是两条间隔和分界线,符号方向别搞反:大于 0 的一侧是类别 1。
