## 结论

数据是 600 个月牙形点(噪声 0.3),420 训练 / 180 测试。

| 实验 | 结果 |
|---|---|
| k=1 | 训练 1.000,测试 0.844 |
| k=50(这组最好) | 训练 0.912,测试 0.883 |
| k=200 | 训练 0.855,测试 0.822 |
| weights=uniform / distance,k=15 | CV 0.9083 / 0.9050 |
| 乳腺癌,原始尺度 / 标准化 | 0.9279 / 0.9649 |
| 距离 p=1 / 2 / 3(标准化后) | 0.9649 / 0.9649 / 0.9648 |

- k=1 训练集满分,测试集最低;测试集曲线中间高两头低,峰值在 k=50 附近。
- k=1 的概率只有 0 和 1,边界是碎块,还有被孤立点围出来的小岛;k 大到 100,过渡带宽得占半张图,月牙的弯都被磨平了。
- 距离权重和距离形式在这份数据上差 0.01 以内,真正要调的是 k 和特征缩放。
- 不标准化 KNN 只有 0.9279,标准化后 0.9649,和 SVM 一样对尺度敏感。

## 踩坑

- 一开始用硬分类画边界,k=1 和 k=15 两张图几乎一样。420 个点铺在二维里,每个 Voronoi 格子太小,边界上的锯齿在图上根本看不清。改成画 `predict_proba` 才把区别显出来。
- k 取偶数在二分类里容易平票,sklearn 会取索引小的那一类。习惯上取奇数。
- `fit` 快不代表模型简单,它只是把数据存起来,`predict` 才是 O(n·d) 的瓶颈。几万条数据在线预测时,要换 KD 树或者近似最近邻。
- 以为 `weights="distance"` 一定更好,实测三个 k 里两个反而更低,属于波动范围。调参之前先确认哪个参数真的起作用。
- 高维下距离会失效,30 维的乳腺癌还撑得住,再高就得先降维。
