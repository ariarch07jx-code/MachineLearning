## 结论

数据是 600 个月牙形点(噪声 0.35),420 训练 / 180 测试,指标统一用 5 折 CV 或测试集。

| 实验 | 结果 |
|---|---|
| 20 棵 bootstrap 单树(同一份测试集) | 平均 0.816,标准差 0.022,最低 0.778 最高 0.856 |
| 单树 CV | 0.8333 |
| 森林(100 棵)CV | 0.8717 |
| n_estimators 扫描 | 1:0.838,5:0.852,10:0.857,20:0.858,50:0.865,100:0.872,200:0.873 |
| OOB / CV / 测试集(200 棵) | 0.8595 / 0.8717 / 0.8167 |
| 乳腺癌:单树 / 森林 / OOB | 0.9064 / 0.9532 / 0.9673 |

- 森林降的是方差,不是偏差。单树和森林的训练集都能到 1.0,差别全在测试集。
- 树的数量 50 到 100 之后基本饱和,100 和 200 只差 0.001,再堆就是浪费算力。
- 概率面图能直接看出平均的效果:单树是一片片颜色相同的色块,森林是一层层过渡。
- 特征重要性在森林里更均匀。乳腺癌数据上最靠前的 worst perimeter 单树给了 0.800,森林只给 0.134,其余分给了 worst radius 等特征。

## 踩坑

- 一开始想用决策边界对比单树和森林,画出来两张图几乎一样,看不出差别。改成画 `predict_proba` 才对:树是分块的,森林是渐变的。
- `n_estimators=1` 的森林不等于前面那棵单树,因为它用的是 bootstrap 样本;n=2 的 CV 反而比 n=1 低 0.005,树太少时平均没有意义。
- OOB 0.8595 比测试集 0.8167 高 0.04,不是哪里算错了。OOB 用了 420 个训练样本,测试集只有 180 个,样本量不同波动也不同,要和 CV 比才合理。
- 只有两个特征时 `max_features="sqrt"` 等于 1,随机的效果和 `None` 差不多,想看出这一层的作用得用多特征数据。
- 特征重要性是两个特征相关时会在它们之间分摊,单树和森林的数字不能直接比大小,只能看排序。
