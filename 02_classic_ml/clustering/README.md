## 结论

三簇点,500 个,标准差 0.8。

| 实验 | 结果 |
|---|---|
| 手写 K-Means(8 轮) | inertia 1720.7 → 594.8,第 7 轮后不动 |
| sklearn K-Means(k=3) | inertia 594.8,和真实标签 ARI 0.9292 |
| inertia / 轮廓系数 | k=3 时 594.8 / 0.554,k=4 时 509.8 / 0.460 |
| 随机初始化 5 个种子 | 4 个到 594.8,1 个卡在 1142.7 |
| 月牙形数据,K-Means | ARI 0.245,轮廓系数 0.486 |
| 月牙形数据,DBSCAN(eps=0.2) | ARI 1.0,250 + 250 |
| DBSCAN 的 eps | 0.1 变 5 簇 22 个噪声,0.2 正好 2 簇,0.3 合成 1 簇 |

- K-Means 每一步 inertia 都在降,第 7 轮收敛,但它只保证局部最优。
- 肘部法和轮廓系数在这份数据上都指向 k=3。
- 随机初始化有一个种子把两个簇合并了,inertia 直接翻倍;k-means++ 加 `n_init=10` 基本不会踩到。
- 月牙形数据上 K-Means 只能切一条直线,每个簇都是 75% 一个半月加 25% 另一个,ARI 0.245。

## 踩坑

- K-Means 在月牙数据上的轮廓系数有 0.486,单看指标以为分得不错,实际上 ARI 只有 0.245。轮廓系数只管簇内紧不紧,不管形状,这种切一刀各拿一半的分法也能拿高分,所以不能只看指标。
- 写 `KMeans(...).inertia_` 之前忘了 `.fit(X)`,报 `'KMeans' object has no attribute 'inertia_'`,第一次跑直接中断。
- `init="random"` 加上 `n_init=1` 很容易卡在局部最优,调参时别为了省时间把它们都设成 1。
- DBSCAN 的 eps 对结果影响比 K-Means 的 k 还大:0.1 和 0.3 的结果完全不一样,一定要结合数据密度来定。
- K-Means 和 KNN、SVM 一样怕量纲,做聚类前先标准化。
