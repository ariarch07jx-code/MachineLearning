# 降维(PCA)

sklearn 复现。这个目录只有 notebook 和结论,没有单独的 `.py` 实现。

## 文件

| 文件 | 内容 |
|---|---|
| `notebook.ipynb` | 手写 SVD 版 PCA、解释方差、投影、重构误差、标准化对比、30 维数据 |
| `README.md` | 结论、踩坑、还没做的 |

## 结论

| 数据 | 结果 |
|---|---|
| iris 标准化,4 个主成分 | 72.96% / 22.85% / 3.67% / 0.52% |
| iris 前两个主成分 | 累计 95.81% |
| 手写 SVD 与 sklearn | 解释方差比例完全一致 |
| 重构误差(n=1/2/3/4) | 0.2704 / 0.0419 / 0.0052 / 0 |
| iris 不标准化 | 第一主成分 92.46%,载荷 [0.36, -0.09, 0.86, 0.36] |
| 乳腺癌 30 维 | 80% 要 5 个,90% 要 7 个,95% 要 10 个;前两个只有 63.24% |

- iris 降到 2 维后三类自己就分开了,虽然 PCA 完全不知道标签。
- 不标准化的第一主成分解释方差更高(92.46% 对 72.96%),但那是被花瓣长度的量纲带偏的结果,不是真的更好。
- 30 维的乳腺癌数据到 7 维就能保住 90% 的方差,但压到 2 维会丢太多。

## 踩坑

- 手写 SVD 和 sklearn 的主成分符号可能反着,一开始以为算错了。V 和 -V 都是解,符号不影响投影结果。
- 直接对未标准化的 iris 做 PCA,第一主成分看起来特别强(92.46%),实际是被花瓣长度(方差 3.1)支配,萼片宽度(方差 0.19)几乎没参与。
- 一直以为降维之后模型一定更快更准,其实 PCA 不看标签,丢掉的方向可能正好是分类要用的。
- 用 `searchsorted` 算"保留 90% 方差要几个主成分"时,要注意返回值是下标,得 +1。

## 还没做

- 在乳腺癌数据上把主成分加到 30 个,画累计解释方差曲线
- PCA 之后再聚类,和直接聚类的 ARI 对比
- 把第一主成分的载荷和原始特征方差对一遍,量化被量纲带偏的程度
- `whiten=True` 对后续模型的影响
- t-SNE、UMAP 和 PCA 的对比(非线性降维)
- LDA 这类判别式降维,和 PCA 的差别
