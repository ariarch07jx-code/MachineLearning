# datasets

所有数据集统一放这里。

**约定**: 每个数据集一个子文件夹,里面放数据文件 + 一个说明文件(来源、字段含义、下载链接)。

## 常用来源

- Kaggle: https://www.kaggle.com/datasets
- UCI Machine Learning Repository: https://archive.ics.uci.edu/
- Hugging Face Datasets: https://huggingface.co/datasets
- Papers With Code: https://paperswithcode.com/datasets
- 国内: 阿里天池、百度飞桨 AI Studio、和鲸社区(Heywhale)

## 入门建议

先用框架内置的小数据集练手(`sklearn.datasets`、`torchvision.datasets` 里的 MNIST / CIFAR-10 等),再上 Kaggle 经典比赛(Titanic、房价预测)。
